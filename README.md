## Процессор

# Компиляция и запуск
- Для компиляции исходного кода процессора (calc.cpp) необходимо подключить библиотеку raylib.

# Фичи
- **Двухпроходный ассемблер:** Поддержка текстовых меток (labels).
- **Генерация техническоро файла commands.h:** Автогенерация файла с опкодами команд и их хешами по списку команд из текстового файла (аргумент argv[1], по умолчанию "commandsList.txt")
- **Массив указателей на функции:** с помощью макросов позволяет легко расширять набор команд процессора
- **Вывод изображения:** вывод состояния оперативной памяти в качестве изображения с палитрой серого.
- **Поддержка различных типов перехода:** по метке и по номеру инструкции в байткоде.

## Память и регистры
- **Регистры:** Процессор поддерживает 6 регистров: `AX`, `BX`, `CX`, `DX`, `EX`, `FX`.
- **RAM:** Оперативная память размером `6000` байт. Обращение к памяти происходит через квадратные скобки: `PUSH [10]`, `POP [BX]` и `PUSH [10 + AX]`.
- **Версия набора команд и защита от дурака:** при компиляции asm кода в сигнатуру вшивается версия набора команд, которая в последующем проверяется в процессоре при выполнении. Защита от stackOverflow и stackUnderflow.

## Структура исполняемого кода файла
1. **Сигнатура:** 8 байт.
2. **Размер массива исполняемого файла:** 4 байт.
3. **Версия набора команд при компиляции** 12 байт (слово VERS и непосредственно версия).
4. **Массив байткода:** сами инструкции и их аргументы.

## Поддерживаемые команды

### Базовые операции, работа со стеком
* **`PUSH`** - кладет аргумент на стек (возможные аргументы: `const`, `register`, `RAM`).
* **`POP`** - забирает верхнее значение стека (возможные аргументы: `register`, `RAM`).
* **`OUT`** - выводит верхнее значение стека в консоль.
* **`INPT`** - считывает значение со стандартного ввода (клавиатуры) и кладет его на стек.
* **`HLT`** - завершает выполнение кода.

### Арифметические операции
* **`ADD`** - складывает два верхних элемента стека.\
* **`MULT`** - умножает два верхних элемента стека.
* **`DIV`** - делит предпоследний элемент стека на верхний.
* **`SQRT`** - извлекает квадратный корень из верхнего элемента стека.

### Условные и безусловные переходы
*Условные переходы сравнивают два верхних элемента стека и совершают переход по указанному адресу при выполнении условия.*
* **`JMP`** - безусловный переход по указанному адресу.
* **`JA`** - переход, если первый элемент строго больше второго (`>`).
* **`JB`** - переход, если первый элемент строго меньше второго (`<`).
* **`JE`**  - переход, если элементы равны (`==`).
* **`JAE`** - переход, если первый элемент больше или равен второму (`>=`).
* **`JBE`**  - переход, если первый элемент меньше или равен второму (`<=`).
* **`JNE`** - переход, если элементы не равны (`!=`).

### Функции и специальные операции
* **`CALL`** - вызов функции. Сохраняет адрес следующей инструкции и переходит к указанной метке.
* **`RET`** - возврат из функции. Извлекает адрес возврата и переходит по нему.
* **`SHOW`** - вывод изображения из оперативной памяти на экран.

### Расширение набора команд
Для расширения набора команд необходимо довавить ее вручную в текущий файл с набором команд или сгенерировать новый с помощью CmdGen.cpp
Ассемблер: необходимо добавить новую функцию с помощью имеющихся функций парса аргументов и макросов, либо же написать собственную
Процессор: необходимо написать код новой функции, после чего внутри функции InitFuncAdrArr() добавить адресс на новую функцию с помощью макроса.
>опкод новой функции не должен превышать опкод команды HLT (0xF4)

### Макросы ассемблера
* **`CommandCase(cmd, ...)`** - проверяет, совпадает ли хеш последней считаной команды с хешом команды cmd. В случае совпадения записывает копкод cmd, после чего начинает компиляцаю этой команды. В качестве второго аргумента ожидается вызов функция для считывания аргумента конкретного типа (можно с помощью макроса). Реализованы слеующие варианты:
* **`HAVE_DBL_ARG`** - считывает аргумент типа double с помощью функции ParseDouble.
* **`HAVE_REG_ARG`** - считывает имя регистра с помощью функции ParseRegArg.
* **`HAVE_LBL_ARG`** - считывает аргумент - номер метки вида :1 или непосредственный адресс в байткоде с помощью функции ParseLabel.
* **`HAVE_HRD_ARG`** - считывает сложные аргументы (число, имя регистра или их комбинацию вида 5 + AX или [5 + AX]) с помощью функции ParseHardArg. При этом меняет биты кодирующие тип аргумента в опкоде функции.

### Макросы процессора
* **`StdFuncAddr(cmd)`** - кладет адрес функции cmd ## _f на место cmd в массиве адресов функций, где cmd - опкод функции 
* **`CustomFuncAddr(cmd, ...)`** - кладет на место cmd в массиве адресов функций адрес, переданый вторым аргументом.
Примеры:
StdFuncAddr(PUSH);
CustomFuncAddr(JA,  &Branch);
